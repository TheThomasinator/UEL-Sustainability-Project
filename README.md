# Overview
- This is a coursework project required for Year1 Semester2 of the Queen's Computing Course.
- It consists of a front-end, developed in vanilla HTML, CSS & JavaScript, with the exception of the usage of the [Chart.js]([url](https://www.chartjs.org/)) library for JavaScript.
- The back-end is a MySQL Database, of which we connect to from our local side with a dbConnector.php file.
- Git version control was not required, though it made the most sense for a project like this for us to learn & use.

## Content
- We were tasked with choosing a Sustainable Development Goal from [this website]([url](https://sdgs.un.org/goals)) each individually.
- We got back together with fully developed envisions of what project we could do with each of our picked SDGs.
- We went forward with DG's idea, centered around SDG 12, "Responsible Consumption and Production".
- The real, official, main data source, is the [University of East London]([url](https://www.uel.ac.uk/)), of which our project is centered around.
